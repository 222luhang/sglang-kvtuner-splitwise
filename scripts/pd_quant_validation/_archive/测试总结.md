## 🔧 待修复问题

### 问题 1: NIXL POSIX 后端未配置

**错误**: `NIXL KVReceiver Exception`

**原因**: 服务启动时未设置 `SGLANG_DISAGGREGATION_NIXL_BACKEND=POSIX`

**修复**:
```bash
# 在所有节点执行
export SGLANG_DISAGGREGATION_NIXL_BACKEND=POSIX
pkill -f "sglang.launch_server"
./start_prefill_posix.sh  # Prefill 节点
./start_decode_posix.sh   # Decode 节点
```

### 问题 2: 层级量化未启用

**状态**: 当前使用统一量化（所有层相同 bits）

**启用方法**:
```bash
# 启动时添加参数
--kvtuner-layer-config ~/sglang-config/qwen2.5-7b_layer_quant.json
```
